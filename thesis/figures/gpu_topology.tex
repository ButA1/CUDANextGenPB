\caption[Rank-to-GPU topology]{\textbf{Rank-to-GPU topology.} Ranks nest into three
    communicator scopes: \texttt{world\_comm} (every rank in the job),
    \texttt{node\_comm} (ranks sharing a physical node), and \texttt{group\_comm}
    (ranks block-mapped onto the same GPU). Each group's rank~0 (thick ring) is
    that group's \emph{leader}, used only for the distributed AMGX solve.
    Example shown: 2 nodes $\times$ 2 GPUs/node $\times$ 2 ranks/GPU, assuming the
    contiguous rank layout Slurm/mpirun use by default.}
